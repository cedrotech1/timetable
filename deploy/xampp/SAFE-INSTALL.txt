UR Timetable on XAMPP — safe install (does not break other PHP projects)
=======================================================================

Goal
----
  http://localhost/           → your normal XAMPP / PHP sites (unchanged)
  http://localhost/timetable  → this React + Node timetable app


Rules (so nothing breaks)
-------------------------
  1. NEVER edit or delete other folders under htdocs.
  2. ONLY create / use:  C:\xampp\htdocs\timetable\
  3. ONLY add one Include line for httpd-timetable.conf (do not rewrite DocumentRoot).
  4. If htdocs\timetable already exists (old PHP), rename that PHP folder first
     or use path /ur-timetable instead (see httpd-timetable.conf comments).


On this development PC (build)
------------------------------
  1. In timetable-frontend create .env.production from:
       deploy\xampp\frontend.env.timetable.example
  2. npm run build
  3. Copy everything inside timetable-frontend\dist\ to a USB/folder for the server
  4. Also copy deploy\xampp\.htaccess into that same folder (next to index.html)


On the XAMPP server
-------------------
  A. Frontend
     - Create C:\xampp\htdocs\timetable\
     - Paste the built files + .htaccess there
     - Do not put files in htdocs root

  B. Backend (Node)
     - Install Node.js if needed
     - Copy timetable-backend somewhere OUTSIDE htdocs
       e.g. C:\apps\ur-timetable-backend\
     - Set .env using deploy\xampp\backend.env.timetable.example
       (keep your DB password / JWT as you already use)
     - Start:  npm start   (or pm2 / nssm so it survives reboot)
     - Must listen on 127.0.0.1:9000

  C. Apache (add-only)
     - Copy deploy\xampp\httpd-timetable.conf →
         C:\xampp\apache\conf\extra\httpd-timetable.conf
     - Edit httpd.conf: add ONE line:
         Include conf/extra/httpd-timetable.conf
     - Restart Apache in XAMPP Control Panel

  D. Test
     - http://localhost/              → old PHP still works
     - http://localhost/timetable/    → new app login
     - http://localhost/timetable/api/v1/health  (or similar) → Node via proxy


Undo anytime
------------
  - Remove the Include line from httpd.conf
  - Delete only C:\xampp\htdocs\timetable\
  - Stop the Node process
  - Restart Apache
  → all other XAMPP projects remain as before
